# 🎮 Sesotho Learning Game

An interactive educational Java application designed to help users learn the Sesotho language through engaging gameplay and progressive challenges. This project demonstrates full-stack development skills including game design, UI/UX implementation, and educational software architecture.

## 📚 Project Overview

The Sesotho Learning Game is a comprehensive language learning platform built with Java that combines gamification principles with proven educational methodologies. The application showcases proficiency in software engineering, object-oriented programming, and user experience design.

**Live Repository:** [Matela-cyber/sesotho-learning-game](https://github.com/Matela-cyber/sesotho-learning-game)

## 🚀 Getting Started

### Prerequisites
- **Java 8 or higher** (Java 11+ recommended)
- **Git** for version control
- **IDE:** IntelliJ IDEA, Eclipse, or NetBeans (optional)

### Installation & Setup

```bash
# Clone the repository
git clone https://github.com/Matela-cyber/sesotho-learning-game.git
cd sesotho-learning-game

# Compile the project
javac -d bin src/**/*.java

# Run the application
java -cp bin com.sesotho.game.Main
```

### Build with Maven (if configured)
```bash
mvn clean install
mvn exec:java -Dexec.mainClass="com.sesotho.game.Main"
```

## 📖 Learning Experience

### Progressive Curriculum
1. **Level 1: Fundamentals** – Greetings, basic phrases, pronunciation
2. **Level 2: Essential Vocabulary** – Numbers, common words, everyday expressions
3. **Level 3: Grammar** – Sentence structure, verb conjugation, grammatical rules
4. **Level 4: Conversational** – Real-world dialogues, cultural context
5. **Level 5: Advanced** – Complex expressions, regional dialects, cultural nuances

- 🏆 Achievement system with badges and milestones
- ⭐ Progress points and skill ratings

- 📊 Performance analytics and improvement tracking
